# 游戏开发自助餐

静态网页，打开 `index.html` 进入菜单。六个分区均已接入导航，默认使用深色主题，手动切换后保存选择。

- 灵感刷刷区：15 条卡片，包含独立游戏资讯频道，以及作品与视觉参考区。
- Unity 引擎区：8 条卡片，包含代码架构实践，以及视差背景和角色控制器补充教程。
- AI 编程区：4 条卡片。
- 游戏美术区：42 条卡片，按 2D / 3D、素材 / 动画及手工 / AI 路线整理；作品与美术风格参考统一收在灵感区。
- XR 教程：4 条卡片。
- 好用小工具：15 条卡片。

共 88 条卡片、83 个不同链接，包含不同学习路线中重复出现的资源。内容来源：[Miro 课程资料板](https://miro.com/app/board/uXjVJhRcRPg=/)及 Chrome「其他书签 → Lectures → 游戏开发自助餐」书签。

## 内容维护

网站与书签的双向更新流程见[网站与书签双向更新说明](网站与书签双向更新说明.md)。2026-10-18 首次同步记录见[网站与书签同步记录](网站与书签同步记录-2026-10-18.md)。

书签仅保留「游戏开发自助餐 → 网站一级分区 → 书签」的结构，每个分区内直接放全部书签。网站可以按内容需要新增子分区，但应先复用或合并用途重叠的分类，不同步增加书签层级。

日常维护可直接修改 `assets/js/*-data.js`。Unity 的两条补充教程位于 `assets/js/unity-extra.js`。分区使用共用的 `assets/js/inspiration.js` 渲染，支持来源筛选、搜索、本地封面与失败回退。

`assets/data/miro-board.svg` 是本次读取的资料板内容快照，不会在访问网页时请求 Miro。原板没有外链的条目链接回对应 Miro 项目；内嵌文档也保留原板入口。

`scripts/build-resource-pages.py` 可从快照和脚本内的整理规则重新生成四个新页面、数据、导航及 Unity 补充教程。它会覆盖这些生成文件；手工修改后请同时更新脚本，或不要重新生成。

`scripts/sync-resource-images.py` 获取资源网站的分享图、图标及视频封面，保存到本地并更新数据文件。没有可用图片的网站使用包含名称与域名的文字封面。图片来源记录在 `assets/data/image-sources.json`，网页运行时不依赖第三方图片接口。

本次没有运行测试，由用户打开网页确认效果。
